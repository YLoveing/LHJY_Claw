# 📊 每日股票智能分析系统

> ⚠️ **仅供技术研究参考，不做实盘推荐**

A 股智能分析流水线，每日三轮自动执行（早盘/午盘/收盘），覆盖选股→分析→模拟交易→风控全链路。

---

## 核心逻辑

```
大盘择时（波动率→仓位） → 选股器（妙想+多因子→候选） → LLM 评分（0-100） → 模拟交易（凯利建仓+多级风控）
                  ↑                                                    ↓
              情绪引擎 ←──────────────────────────────────────── 量化引擎（GARCH/HMM/马科维茨）
```

四句话概括：

1. **仓位比选股重要** — 波动率择时夏普 1.43 > 纯选股 alpha ≈ 0（修正幸存者偏差后）
2. **买入看评分+凯利** — LLM 评分 ≥ 68 触发，凯利公式算仓位，半凯利+情绪系数双重收紧
3. **卖出去中心化** — 止损-8% / 止盈+25%减半 / 时间止损 / 低评分清理 / 大盘DANGER，谁先到谁执行
4. **全链路降级** — 每个数据点 2-3 个独立源，全部挂也不阻断交易

## 大盘择时（仓位管理）

三层过滤，取最保守：

### 1️⃣ 五因子波动率择时（主信号）
沪深300 + 中证全指双指数。

| 20日波动率百分位 | 仓位 |
|:--------------:|:----:|
| < 30% | 100% 🟢 |
| 30%~60% | 75% 🟡 |
| 60%~80% | 50% 🟠 |
| ≥ 80% | 25% 🔴 |

五个因子：HV波动率 / 资金流向 / 量能 / 均线偏离 / MACD动量。策略回测夏普 1.43。

### 2️⃣ MA 趋势（中长线）
沪深300相对MA60的位置：上方→满仓，下方→25%，发散空头→只卖不买。

### 3️⃣ 实时涨跌幅（短线）
```
≤ -3%  → DANGER（只卖不买）
≤ -1.5% → CAUTION（不开新仓）
> -1.5% → normal
```

数据源自动降级：东方财富 → 腾讯财经 → akshare 日K，全部不可用则 normal（不因网络抖动锁仓）。

## 选股 → 评分 → 交易

### 候选池形成
```
每日候选 = 选股器TOP5 + 固定池(002410,510300) + 当前持仓
```
持仓代码自动注入（5/27 修的那个 bug），确保已有仓位每天被重新评分。

### LLM 评分
0-100 分，基于技术面（MA排列/量价/MACD）+基本面（ROE/增速）+市场情绪。

- 买入阈值 ≥ 68（动态，受 GARCH 波动率影响）
- 卖出阈值 ≤ 40
- 评分 ≥ 70 需通过量化确定性校验（成交量、MA20、RSI）
- 跳空 ≥ 2% 评分打九折

### 模拟交易

| 逻辑 | 规则 |
|:----|:-----|
| **买入** | 评分 ≥ 阈值，凯利公式算仓位，半凯利×情绪系数，行业集中度 ≤ 40% |
| **止损** | 浮亏 -8% → 全平 |
| **止盈** | 浮盈 +25% → 减半仓锁利，之后每 +10% 再减半 |
| **时间止损** | 持有 ≥ 20天 且 浮亏 ≤ -8% → 强平 |
| **低评分清理** | 进场评分 < 当前买入阈值 → 清仓 |
| **再平衡** | 评分变化 < 5 分不触发（防频繁交易） |
| **账户回撤** | ≥ -20% 暂停买入，≥ -30% 强平所有 |
| **滑点** | 买入+0.1%，卖出-0.1% |

三种策略并行对比：默认(≥68/≤40) / 趋势(≥65/≤35) / 均值回归(≥75/≤25)


## 风控矩阵

| 风险 | 检测 | 响应 |
|:----|:-----|:-----|
| 大盘暴跌 ≥ 3% | 实时涨跌幅 | 只卖不买 |
| 个股浮亏 ≥ 8% | 每日扫描 | 强平 |
| 个股浮盈 ≥ 25% | 每日扫描 | 减半仓 |
| 持有20天+亏8% | 时间止损 | 强平 |
| 账户回撤 ≥ 20% | 每日扫描 | 暂停买入 |
| AI评分幻觉 | 确定性校验 | 拒绝买入 |
| 数据源故障 | 三级降级 | 自动切备用 |
