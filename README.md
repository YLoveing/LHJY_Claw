# 📊 每日股票智能分析系统

> ⚠️ **仅供技术参考，不做实盘推荐**
>
> 本项目纯属个人学习研究用途的量化交易实验系统。
> 所有信号、评分、报告均基于历史数据和AI模型生成，**不构成任何投资建议**。
> 实盘交易风险自担，作者不对任何投资损失负责。

---

## 一、一句话说明

每天收盘后算一遍自选股，告诉你**三个事**：

```
📗 买什么  →  候选股 + 买入条件
📕 卖什么  →  持仓止损/止盈触发
📘 不动    →  持仓正常无需操作
```

没有大盘复盘、没有3000字分析报告、没有情绪指数推送。只看信号。

## 二、系统架构

```
cron 触发 ──→ run_and_send.sh ──→ 后端全量跑
                                      │
                                      ├── 选股器 (MX/全A扫描)
                                      ├── 全量分析 (LLM决策信号)
                                      ├── 模拟交易 (持仓+风控)
                                      ├── 量化引擎 (GARCH/HMM/马科维茨)
                                      └── 情绪引擎 (恐慌/贪婪)
                                            │
                                            只推"三句话"
                                            ↓
                                      用户收到: 📗📕📘
```

## 三、每日时间线

```
09:25 ── 早盘
         ├── 选股器（MX选股→技术面筛选→LLM评分→策略匹配）
         ├── 执行昨日 pending 信号（开盘价买入）
         ├── MX财务预取
         ├── 全量分析 + 模拟交易
         └── 推送 📗 今日买入关注（3只）

11:30 ── 午盘
         ├── MX财务预取
         ├── 精简分析
         └── 不推送（盘中异动由 monitor 自行处理）

09:30~14:50 ── 盘中监控（每10分钟）
         ├── 检测建仓信号（放量突破/早盘强势/回踩企稳）
         ├── 持仓风控检查（止损/止盈/跟踪止损）
         └── 异常波动告警

18:00 ── 收盘（核心时段）
         ├── 选股器（选次日候选股）
         ├── 全量分析 + 模拟交易
         ├── 量化引擎（GARCH/HMM/马科维茨）
         ├── 情绪引擎（恐慌/贪婪）
         ├── 信号准确率统计
         └── 推送 📗📕📘 完整三句话 + ⚠️ 极值告警
```

### A股T+1制度说明

- 盘中检测到的建仓信号 → 写入待执行队列（`pending_signals.json`）
- **次日上午09:25** 以开盘价统一执行
- 止损/止盈按日频管理，不强制收盘平仓

## 五、策略概览

### 买入

| 条件 | 说明 |
|------|------|
| 候选来源 | 选股器（全A扫描/MX选股）→ 技术面筛选 → LLM评分 → 策略匹配 |
| 评分阈值 | ≥70（GARCH高波动→78，情绪低迷→62） |
| 仓位 | 半凯利 × 分散系数0.25 |
| 信号交易 | 盘中检测→次日09:25执行，单只≤¥8,000 |
| 硬性检查 | 量比≥1.2 + 价在MA20上 + RSI≤70 + 大盘择时 |

### 卖出

| 条件 | 阈值 | 动作 |
|------|:----:|------|
| 硬止损 | -15% | 强制卖出 |
| 时间止损 | 20天+浮亏-8% | 强制卖出 |
| 多级止盈 | +10% / +25% | 减半仓 / 清仓 |
| 信号交易止损 | -3% | 单只出场 |
| 信号交易止盈 | +5% | 单只出场 |
| 跟踪止损 | 浮盈3%→回撤-4% | 单只出场 |
| 账户熔断 | 总权益回撤-20% | 暂停所有买入 |

### 量化引擎（后台运行，不推送）

| 引擎 | 用途 |
|------|------|
| **GARCH(1,1)** | 波动率建模 → 动态调整买卖阈值 |
| **HMM** | 市场状态识别（牛/震荡/熊） |
| **马科维茨CLA** | 有效前沿 → 最优权重 → 再平衡 |
| **情绪指数** | 恐慌/贪婪 → 仓位系数±50%调节 |

> 量化引擎为策略的辅助层。即使模型失效，阈值退回默认值70也能正常运行，不是主信号源。

## 七、风险声明

1. **⚠️ 不做实盘推荐**：本系统为个人学习研究用途，所有信号基于历史数据和AI模型生成，不构成投资建议，实盘风险自担。
2. **AI幻觉风险**：AI评分可能包含幻觉信息（约14%），确定性校验层用于兜底，但不能完全消除。
3. **策略局限性**：量化模型在极端行情下可能失效。过去表现不代表未来收益。
4. **小资金约束**：¥30,000初始资金受最低佣金约束，费用侵蚀效应显著。
5. **单点故障**：依赖crontab定时触发 + 东方财富API，进程异常或接口变动可能导致系统异常。
