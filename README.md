# LHJY_Claw — 个人量化交易系统

基于 DeepSeek LLM 评分 + GARCH 波动率模型 + 凯利仓位管理的全自动化 A 股量化交易系统。

## 架构

```
┌─────────────────────────────────────────────────────┐
│                     输入层                           │
│  Docker分析器 (DeepSeek LLM) + 选股器 (技术面筛选)     │
├─────────────────────────────────────────────────────┤
│                     分析层                           │
│  GARCH(1,1) 波动率 → 动态买卖阈值                     │
│  HMM 市场状态检测 → 持仓偏好调节                      │
│  马科维茨均值-方差 → 组合优化再平衡                    │
│  情绪指数 (涨跌比/涨停数/成交量/涨跌幅/均线)           │
├─────────────────────────────────────────────────────┤
│                     执行层                           │
│  半凯利仓位管理 (赔率1.67) × 情绪系数 × 分散系数      │
│  止损 -15% / 止盈 +25%减半 / 账户回撤 -20%暂停        │
├─────────────────────────────────────────────────────┤
│                     推送层                           │
│  QQ + 微信 三时段推送 (9:00 盘前 / 13:00 盘中 / 18:00 盘后) │
│  每月信号准确率统计 + 周五绩效周报                     │
└─────────────────────────────────────────────────────┘
```

## 运行方式

### 定时执行 (推荐)

系统通过 cron 在工作日自动运行：

| 时间 | 任务 | 说明 |
|------|------|------|
| 9:00 | 选股器 + 早盘分析 | 全A扫描→候选池→LLM评分→模拟交易→推送 |
| 13:00 | 午盘跟踪 | 持仓复核→止损检查→推送 |
| 18:00 | 收盘复盘 | 选股器扫描→量化引擎→情绪引擎→模拟交易→推送 |

### 手动执行

```bash
cd /opt/daily_stock_analysis
bash run_and_send.sh          # 完整流水线
python3 run_screener.py       # 仅选股器
python3 simulated_trading.py  # 仅模拟交易
```

## 模块说明

### 选股器 (`screener/stock_screener.py`)
- 全A股扫描 → 基础过滤(价>3/成交额>0.3亿/非ST) → 技术面筛选(多头排列/放量突破/金叉/超卖反弹)
- 输出 Top 15 候选送至量化评分

### 量化引擎 (`quant_engine/`)
- `garch.py` — GARCH(1,1) MLE 条件波动率估计，驱动动态买卖阈值
- `hmm_market.py` — 3维高斯观测 HMM 市场状态检测
- `markowitz.py` — 关键线算法(CLA) 有效前沿+马科维茨组合优化
- `run_quant.py` — 统一入口

### 模拟交易 (`simulated_trading.py`)
- 凯利仓位公式 + 情绪系数调节
- 三层风控：单只止损-15% / 单只止盈+25%减半 / 账户回撤-20%暂停
- 周五风险平价再平衡

### 情绪引擎 (`sentiment_engine/sentiment_index.py`)
- 5维度综合指数：涨跌比、涨停数、成交量、涨跌幅、50日均线

### 推送 (`run_and_send.sh`)
- QQ 频道机器人 + 企业微信双通道推送
- 三时段差异化报告：盘前预测 / 盘中跟踪 / 盘后复盘

| 胜率 | 22.2% | **43.1%** |
