## 二、仓位管理 —— 波动率择时 ⭐

**信号源**：沪深300 + 中证全指双指数，取最保守值。

| 20日波动率百分位 | 建议仓位 | 含义 |
|:--------------:|:-------:|:----:|
| < 30%（低波动） | **100%** | 🟢 满仓 |
| 30% ~ 60%（正常） | **75%** | 🟡 正常 |
| 60% ~ 80%（偏高） | **50%** | 🟠 适度 |
| ≥ 80%（高波动） | **25%** | 🔴 轻仓 |

**算法**：20日滚动波动率 ÷ 过去120天历史百分位。零参数调优，无未来函数。

### 策略回测（2024/05 ~ 2026/05 中证全指）

| 策略 | 总收益 | 最大回撤 | 夏普 |
|:----|:-----:|:-------:|:---:|
| 买入持有 | +55.13% | 14.71% | 1.17 |
| **🔥 波动率择时** | **+57.08%** | **11.04%** | **1.43** 🏆 |
| MA60/120均线过滤 | +41.96% | 11.04% | 1.08 |
| 动量20日 | +36.68% | 11.04% | 1.05 |

> **结论**：大盘择时比选股重要100倍。全市场波动率择时夏普1.43，开箱即用。

## 三、选股 —— 全A扫描

**流程**：
1. 全A股实时行情快照（东方财富 API）
2. 技术面筛选（量比≥1.2、价格在MA20上方、RSI≤70）
3. LLM多因子评分（趋势30%、量价20%、基本面30%、市场环境20%）
4. 策略匹配（7种交易形态）
5. 输出候选股（最多5只）

| 硬性检查 | 量比≥1.2、价在MA20上、RSI≤70、大盘非danger |

## 十、量化引擎（辅助层）

| 引擎 | 用途 |
|:----|:----|
| **波动率择时** | 🏆 主力仓位管理 |
| **GARCH(1,1)** | 波动率建模 → 动态调整买卖阈值 |
| **HMM(4状态)** | 市场状态识别（多/空/震荡/高波动） |
| **情绪指数** | 恐慌/贪婪 → 辅助仓位调节 |
| **马科维茨CLA** | 有效前沿 → 最优权重 |

> 量化引擎为策略辅助层，即使模型失效，波动率择时信号仍独立运行。

## 十一、幸存者偏差修正

沪深300回测中发现严重幸存者偏差：

| 版本 | 处理 | 收益 | 夏普 |
|:---:|:----|:---:|:---:|
| V3（未修正） | 用今日成分股回测过去 | +70.32% | 1.24 |
| V4（修正） | 按纳入日期过滤 | +0.20% | 0.09 |

**修正方法**：每只股票有 `纳入日期` 字段，交易日只允许已纳入的成分股参与评分交易。修正后结论：纯选股alpha几乎为零，超额收益来源于大盘择时。

## 十二、风险声明

1. **⚠️ 不做实盘推荐**：本系统为个人学习研究用途，所有信号基于历史数据和AI模型生成，不构成投资建议。

3. **波动率择时局限性**：低波动→满仓逻辑在尖顶反转时可能来不及减仓。
4. **AI幻觉风险**：LLM评分可能包含幻觉信息。
5. **单点故障**：依赖crontab + 东方财富API，接口变动可能导致系统异常。
