## 一、系统架构

```
         ┌───────────────────────────────────────────────┐
         │                 cron 定时调度                    │
         │      run_and_send.sh（09:25 / 11:30 / 18:00）   │
         └──────────────┬────────────────────────────────┘
                        │
         ┌──────────────▼────────────────────────────────┐
         │              main.py（主调度）                    │
         │     Pipeline 引擎（src/core/pipeline.py）        │
         └────┬─────────┬──────────┬──────────┬─────────┘
              │         │          │          │
     ┌────────▼──┐ ┌───▼────┐ ┌──▼────┐ ┌───▼────────┐
     │ 数据获取   │ │ 选股   │ │ 分析   │ │ 模拟交易    │
     │ data_prov. │ │screener│ │analys. │ │simul_trad. │
     └────────┬───┘ └───┬────┘ └──┬────┘ └───┬────────┘
              │         │        │          │
     ┌────────▼──┐ ┌───▼────┐ ┌──▼────┐ ┌───▼────────┐
     │ 风险层     │ │量化引擎│ │情绪   │ │ 执行层      │
     │ risk_lay  │ │ quant │ │senti.│ │ exec_layer  │
     └───────────┘ └────────┘ └───────┘ └────────────┘
```

**核心设计原则：**

| 原则 | 说明 |
|------|------|
| **数据源多级降级** | 每个数据点至少 2-3 个独立源，主源挂后自动降级 |
| **风控 > 收益** | 止损 -15%、止盈 +25%（减半仓）、账户回撤 -20% 暂停 |
| **整体仓位 > 个股选择** | 波动率择时夏普 1.43 > 纯选股 alpha |
| **生产代码 = 回测代码** | 回测必须 import 生产模块，杜绝自写一套费率/止损 |

## 二、核心执行流程

```
09:25（早盘）
  ├── 选股器扫描（run_screener.py → MX妙想 / 技术指标）
  ├── 执行昨日待执信号（intraday_trading.py execute）
  ├── 妙想财务数据预取（mx_enrich.py）
  ├── 多因子 B 策略评分（multi_factor_production.py）
  ├── 全量分析（main.py → pipeline）
  ├── 波动率择时信号（vol_timing.py）
  └── 模拟交易执行（simulated_trading.py）
       └── 数据入库 SQLite（daily_import_sim.py）

11:30（午盘 — 精简快照）
  ├── 妙想财务预取
  └── 午盘快照分析（main.py --force-run，跳过模拟交易）

18:00（收盘 — 完整复盘）
  ├── 选股器扫描（选次日候选）
  ├── 多因子策略评分
  ├── 全量分析 + 模拟交易
  ├── 量化引擎（GARCH / HMM / 马科维茨）
  ├── 情绪引擎（市场情绪指数）
  ├── 信号准确率统计
  └── 周五：30 日回测 + 周报
```

## 四、大盘择时（仓位管理）

大盘择时是系统收益的最大来源。三层过滤，取最保守结果。

### 4.1 五因子波动率择时（主信号）

**信号源**：沪深 300 + 中证全指双指数，取更保守值。

| 20日波动率百分位 | 建议仓位 | 含义 |
|:--------------:|:-------:|:----:|
| < 30%（低波动） | **100%** | 🟢 满仓 |
| 30% ~ 60%（正常） | **75%** | 🟡 正常 |
| 60% ~ 80%（偏高） | **50%** | 🟠 适度 |
| ≥ 80%（高波动） | **25%** | 🔴 轻仓 |

**五个因子**：

| 因子 | 计算方式 |
|:----|:---------|
| HV 波动率 | 20日滚动年化波动率 ÷ 历史百分位 |
| 资金流向 | 主力资金净流入 / 总成交额 |
| 量能 | 当日成交量 / 20日均量 |
| 均线 | 价格 / MA60 偏离度 |
| MACD | DIF - DEA 动量 |

**历史回测**（2024/05 ~ 2026/05，中证全指）：

| 策略 | 总收益 | 最大回撤 | 夏普 |
|:----|:-----:|:-------:|:---:|
| 买入持有 | +55.13% | -14.71% | 1.17 |
| **🔥 波动率择时** | **+57.08%** | **-11.04%** | **1.43** |
| MA60/120均线 | +41.96% | -11.04% | 1.08 |
| 动量20日 | +36.68% | -11.04% | 1.05 |

> **结论**：大盘择时比选股重要 100 倍。全市场波动率择时夏普 1.43，开箱即用。

### 4.2 MA 趋势过滤（中长线）

基于沪深 300 指数的 MA 均线位置决定仓位：

| 状态 | 条件 | 仓位比例 |
|:----|:----|:--------:|
| 强势多头 | MA60 上方且 MA5 > MA10 > MA20 发散 | 100% |
| 多头 | MA60 上方 | 100% |
| 盘整 | MA60 附近缠绕 | 50% |
| 空头 | MA60 下方 | 25% |
| 强势空头 | MA60 下方且均线发散 | 只卖不买 |

### 4.3 实时涨跌幅过滤（短线）

```
沪深300当日涨跌幅 ≤ -3.0% → DANGER：只卖不买
                ≤ -1.5% → CAUTION：不开新仓
                > -1.5% → normal
```

**数据源三级降级**：

```
东方财富 push2 ──→ 腾讯财经 ──→ akshare 日K
    ❌故障           ✅正常           ❌仅备用
```

当所有数据源均不可用时，降级为 `normal`（不因网络抖动阻断交易），仅依赖 MA 趋势保护。

## 五、选股体系

### 5.1 妙想选股（MX）

通过 MX 金融搜索 API 进行条件选股，支持：

- **行情指标**：涨跌幅、换手率、量比、振幅
- **财务指标**：ROE、净利润增速、毛利率、PE/PB
- **技术形态**：突破、金叉、超跌反弹

### 5.2 多因子打分

对全 A 股（约 5000 只）进行广度打分，选出前 10 只候选。因子维度：

| 因子 | 权重 | 说明 |
|:----|:---:|:----|
| 量价趋势 | 30% | MA排列、量价配合 |
| 资金流向 | 20% | 主力 / 北向资金 |
| 波动率 | 15% | 20日年化波动百分位 |
| 估值 | 15% | PE 历史百分位 |
| 基本面动量 | 20% | 营收/净利润增速 |

### 5.3 LLM 评分分析

基于大模型（DeepSeek / Claude）对候选股进行技术面和基本面交叉评分：

- 评分范围：0-100
- 买入阈值：动态（默认 ≥ 68）
- 卖出阈值：动态（默认 ≤ 40）
- 关键校验：
  - 评分 ≥ 70 的候选需通过量化确定性校验（成交量 > 5日均量×1.2、收盘价在 MA20 上方、RSI ≤ 70）
  - 跳空超过 ±2% 评分打折 0.9

### 5.4 每日候选池形成

```
候选池 = 选股器TOP5 + 固定池(002410, 510300) + 当前持仓 + 多因子持仓
```

**关键设计**：当前持仓代码自动注入候选池（`run_and_send.sh`），确保已有仓位每天都能被重新评分，触发再平衡或止损决策。

## 六、模拟交易引擎

初始资金 30,000 元，模拟真实交易环境。

### 6.1 买入逻辑

1. **凯利公式**：根据评分计算仓位比例

   ```
   K% = (bp - q) / b = (score/100 × 赔率 - (1-score/100)) / 赔率
   ```

2. **半凯利控制**：实际仓位 = 凯利 × 0.5 × 情绪系数 × 仓位上限限制
3. **行业集中度**：单一行业不超过 40%
4. **滑点模拟**：买入上浮 0.1%，卖出下浮 0.1%
5. **情绪调节**：贪婪（系数 0.8）→ 保守；恐惧（系数 1.2）→ 激进

### 6.2 卖出逻辑

| 触发条件 | 动作 | 参数 |
|:---------|:----|:----|
| 评分 ≤ 卖出阈值 | 清仓卖出 | 动态阈值（默认 ≤ 40） |
| 浮盈 +25% | 减半仓锁利 | TAKE_PROFIT = 25%，之后每 +10% 再减半 |
| 止损 -8% | 全仓卖出 | STOP_LOSS = -8%（收紧） |
| 时间止损 | 持有 ≥ 20 天 + 浮亏 -8% | TIME_STOP |
| 低评分清理 | 进场评分 < 买入阈值 | 脏数据保护 |
| 评分变化 < 5 分 | 不触发再平衡 | 避免频繁交易 |

### 6.3 风控体系

```
┌─ 个股层面 ──────────────────────────────────┐
│ 止损 -8%（硬止损） → +25%（减半仓锁利）       │
│ 时间止损：20天 + 浮亏-8% → 强制平仓           │
│ 评分下降：低于阈值卖出                        │
├─ 账户层面 ──────────────────────────────────┐
│ 总回撤 -20% → 暂停所有买入                   │
│ 硬性回撤 -30% → 强制平所有仓                  │
│ 大盘 DANGER → 只卖不买                      │
├─ 数据源层面 ────────────────────────────────┤
│ 东方财富故障 → 腾讯财经降级                    │
│ 全部数据源挂 → 降级 normal，不阻断交易          │
└────────────────────────────────────────────┘
```

### 6.4 多策略对比

| 策略 | 买入阈值 | 卖出阈值 | 单笔限额 | 上限 |
|:----|:-------:|:-------:|:-------:|:---:|
| 默认（主策略） | ≥ 68 | ≤ 40 | 按凯利 | 8只 |
| 趋势策略 | ≥ 65 | ≤ 35 | 4万 | 8只 |
| 均值回归 | ≥ 75 | ≤ 25 | 6万 | 6只 |

## 八、量化引擎

收盘后运行（`quant_engine/run_quant.py`），为次日决策提供参考。

### 8.1 GARCH(1,1) 波动率

```python
σ²_t = ω + α·ε²_{t-1} + β·σ²_{t-1}
```

- MLE 网格搜索 + BFGS 两步优化
- Hessian 逆 → 参数标准误
- α + β < 1 平稳约束
- 输出：条件波动率 → 动态买卖阈值

### 8.2 HMM 市场状态识别

- 3 维高斯观测（收益率、波动率、成交量变化）
- Baum-Welch + Viterbi 解码
- 10 次随机重启避免局部最优
- log-space 前向后向（数值稳定）
- 输出：牛/熊/盘整 概率分布

### 8.3 马科维茨组合优化（CLA）

- 关键线算法（Critical Line Algorithm）精确求解有效前沿
- 收缩协方差估计（Ledoit-Wolf）
- 输出：有效前沿曲线 → 最优权重建议

## 十、风险控制矩阵

| 风险类型 | 检测方式 | 响应措施 |
|:---------|:---------|:---------|
| 大盘暴跌 ≥ 3% | 实时涨跌幅 | DANGER：只卖不买 |
| 大盘下跌 ≥ 1.5% | 实时涨跌幅 | CAUTION：不开新仓 |
| 个股浮亏 ≥ 8% | 每日扫描 | 强制平仓 |
| 个股浮盈 ≥ 25% | 每日扫描 | 减半仓锁利 |
| 持有 ≥ 20天 + 浮亏 ≥ 8% | 时间止损 | 强制平仓 |
| 账户回撤 ≥ 20% | 每日扫描 | 暂停买入 |
| 账户回撤 ≥ 30% | 每日扫描 | 强制平所有仓 |
| AI 评分幻觉 | 确定性校验 | 拒绝买入 |
| 跳空 ≥ 2% | 开盘价偏差检查 | 评分打折 0.9 |
| 数据源故障 | 三级降级 | 自动切备用源 |
| 选股器空列 | 白名单保护 | 保留固定池 |

## 十三、幸存者偏差修正

沪深 300 回测中发现严重幸存者偏差：

| 版本 | 处理 | 收益 | 夏普 |
|:---:|:----|:---:|:---:|
| V3（未修正） | 用今日成分股回测过去 | +70.32% | 1.24 |
| V4（修正） | 按纳入日期过滤成分股 | +0.20% | 0.09 |

**修正方法**：每只股票记录纳入日期，交易日只允许已纳入的成分股参与评分交易。
**结论**：纯选股 alpha 几乎为零，超额收益来源于大盘择时。

## 十四、风险声明

1. ⚠️ **不做实盘推荐**：本系统为个人学习研究用途，所有信号基于历史数据和 AI 模型生成，不构成投资建议。
2. **幸存者偏差**：历史回测收益已被修正，但无法完全消除其他形式的偏差。
3. **波动率择时局限性**：低波动 → 满仓逻辑在尖顶反转时可能来不及减仓。
4. **AI 幻觉风险**：LLM 评分可能包含幻觉信息。
5. **单点故障**：依赖 cron + 数据源 API，接口变动可能导致系统异常。
6. **实盘差异**：模拟交易的滑点、费率与实际交易存在差异。
