## 五、卖出策略

### 5.1 强制风控（每日执行）

#### 硬止损
- 单只从均价跌超 **-15%** → 全仓强制卖出

#### 时间止损（P2）
- 持有超过 **10个交易日**
- 且浮亏超 **-5%**
- → 强制平仓释放资金

#### 多级止盈（P2）

| 级别 | 浮盈 | 动作 |
|:----:|:----:|------|
| 🥇 | **+10%** | 减半仓锁利 |
| 🥈 | **+25%** | 清仓收工 |

> 止盈级别通过 `tp_level` 追踪：0→未触发 → 1→一级已触发 → 2→全部已完成

### 5.2 动态阈值卖出

- AI评分 **≤ 40~48**（动态）→ 评分驱动卖出
- 评分变化 **< 5分** → 跳过（减少无效交易）

|:----:|:------|

| **14:50** | 强制收盘平仓 |

### 5.4 账户级熔断

| 条件 | 动作 |
