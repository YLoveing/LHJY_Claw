# 多因子选股策略优化方案

> 设计：Hermes 🐴 | 日期：2026-06-10 | 目标：Sharpe > 1.0 且 Max Drawdown < -20%

## 一、关键发现

### 1.1 因子量纲差异（致命问题）

**当前等权打分存在严重的量纲不匹配**——各因子原始值的数值范围相差 2~3 个数量级：

| 因子 | 均值 | 标准差 | 典型范围 | 等权贡献 |
|------|------|--------|---------|---------|
| rsi_14 | 60.2 | 15.7 | 26~89 | **~60** ← 主导 |
| rsi_6 | 59.9 | 23.1 | 10~100 | **~60** ← 主导 |
| volume_ratio | 0.88 | 0.55 | 0.4~3.9 | ~0.9 |
| volume_trend | 0.14 | 0.25 | -0.3~0.8 | ~0.14 |
| mom_3m | 0.14 | 0.64 | -0.3~3.8 | ~0.14 |
| price_ma60 | 0.06 | 0.20 | -0.2~1.2 | ~0.06 |
| vol_60d | 0.43 | 0.18 | 0.16~0.99 | ~0.43 |

**结论**：当前基准策略（mom_3m + vol_60d + price_ma60 + volume_trend + rsi_14 等权）实质上 ≈ 纯 RSI 策略（低买超卖），其他因子的贡献被淹没在 RSI 的 100x 量级差异中。

### 1.2 IC 分析揭示：均值回归主导

所有因子的 mean IC 均为**负值**（更高因子值 → 更低未来收益），部分统计显著：

| 因子 | 5日 forward IC | IR | t-stat |
|------|------------|-------|--------|
| mom_60d | **-0.051** | -0.27 | -6.48 |
| volatility_20d | -0.039 (1d) | -0.16 | -3.83 |
| vol_ratio | -0.023 | -0.20 | -4.74 |
| mom_20d | -0.033 | -0.17 | -4.19 |
| close_vs_ma60 | -0.030 | -0.15 | -3.40 |
| RSI | -0.018 | -0.11 | -2.54 |

**核心洞察**：在 2024-2026 年 A 股市场区间，**均值回归 > 趋势跟随**。高动量股票随后表现更差，放量后容易回撤，高波动伴随下跌。这与机构资金"高抛低吸"的行为模式一致。

### 1.3 数据可用性约束

- 总交易日：333 天（2024-12-18 ~ 2026-05-08）
- 前 32 天只有少量股票（<100只），2025-02-12 起才有完整 1542 只
- **有效回测起点**：2025-02-12（1000+ 股票，300 个交易日）
- mom_3m 需要 64 天历史 → 有效因子起点：~2025-03-20
- mom_6m 需要 127 天历史 → 有效因子起点：~2025-06-20
- **Walk-forward 建议**：train 4个月 / test 2个月 → 可得约 4 折

## 二、策略设计核心

### 2.1 必须引入因子归一化

在打分前对每个因子做**横截面 z-score 标准化**（每个交易日，将所有股票的因子值转为均值0标准差1的分布）。这会消除量纲差异，让每个权重真正发挥作用。

```
标准化值 = (原始值 - 当日横截面均值) / 当日横截面标准差
```

**如果不引入标准化**，则需要按量纲反比调整权重（等效于人工归一化）。本方案同时提供两组权重：标准化权重（推荐）和原始值权重（备选）。

### 2.2 因子选择逻辑

基于 IC 方向和实战经验，将 14 个因子分为 4 层：

| 层级 | 因子 | 方向 | 逻辑 |
|------|------|------|------|
| **反转层** | mom_3m, mom_6m | **负向** | 高动量股票随后回撤，买弱卖强 |
| | rsi_14, rsi_6 | **负向** | 避免追高，低 RSI 有望反弹 |
| | close_low_20 | **正向** | 在区间低位的股票更容易反弹 |
| **质量层** | volatility_60d | **负向** | 低波动 = 更稳定的反弹基础 |
| | max_dd_60d | **负向** | 回撤已大的股票继续跌概率低 |
| | volume_trend | **负向/正向** | 量能萎缩可能是底部，放量可能见顶 |
| **确认层** | price_ma60 | **正向** | 在均线上方 = 基本面支撑更强 |
| | short_long_ma | **正向** | 短期均线在长期上方 = 趋势未坏 |
| **分散层** | mom_1m | **负向** | 短线动量反转（可选） |
| | volume_ratio | **负向** | 当日放量后次日容易回调 |
| | volatility_20d | **负向** | 短期波动高的股票风险大 |

### 2.3 注意：因子经济学含义可能随时间变化

当前 IC 显示强烈的均值回归特征，但在牛市中 momentum 因子可能转正。应定期（每月）重算 IC 以监控因子方向是否反转。

## 三、策略候选方案

### 策略 A：稳健反转（推荐首选）

**设计理念**：以均值回归为核心，辅以质量筛选，控制回撤。因子少但每个都有明确的经济学含义。

**标准化因子权重**（总和归一化）：

```
mom_3m:       -0.30    # 3个月动量反转（最强IC信号）
mom_1m:       -0.10    # 1个月短线反转
volatility_60d: -0.15  # 低波动偏好
max_dd_60d:   -0.15    # 避免追入已经超跌的（但也不能追高）
price_ma60:    0.15    # 在均线附近或上方（基本面支撑）
volume_trend:  0.10    # 量能缩量（可能底部特征）
close_low_20:  0.05    # 区间低位（反转潜力）
```

**原始值等效权重**（如果不做标准化，按典型范围调整）：

```

volatility_60d: -0.90  # 范围~1.9, 等效贡献~1.71
```

**推荐参数**：

## 五、Walk-Forward 验证方案

### 5.1 折数设计

有效回测期：2025-03-20 ~ 2026-05-08 ≈ 250 个交易日 ≈ 12 个月

```
Fold 1: Train 2025-03-20 ~ 2025-07-20  | Test 2025-07-21 ~ 2025-09-20
Fold 2: Train 2025-05-20 ~ 2025-09-20  | Test 2025-09-21 ~ 2025-11-20
Fold 3: Train 2025-07-20 ~ 2025-11-20  | Test 2025-11-21 ~ 2026-01-20
Fold 4: Train 2025-09-20 ~ 2026-01-20  | Test 2026-01-21 ~ 2026-03-20
Fold 5: Train 2025-11-20 ~ 2026-03-20  | Test 2026-03-21 ~ 2026-05-08
```

每折 train=4个月, test=2个月, 50%重叠。

### 5.2 验证流程

```
for each fold:
  1. 在 train 集上跑 36 组参数，选 Sharpe 最高的 Top-3
  2. 在 test 集上评估这 Top-3，记录表现
  3. 汇总 5 折的 test 表现，计算平均 Sharpe 和稳定性（标准差）
```

**过拟合判断标准**：
- 如果 train 集最优 ≠ test 集最优的概率 > 60% → 过拟合
- 如果同一参数在 ≥4 折 test 中都排进 Top-3 → 稳健
- 如果 max drawdown 在 train/test 之间波动 >15% → 不稳定

### 5.3 最终全样本验证

选出 walk-forward 表现最稳定的参数后，在完整数据集（2025-03-20 ~ 2026-05-08）上跑一次完整回测作为最终结果展示。

## 六、风险提示

### 6.1 策略风险

1. **因子方向反转风险**：当前 IC 显示强烈均值回归，但如果市场转入单边牛市，反转策略可能大幅跑输。需设置止损或加入市场状态判断。

2. **数据期限过短**：333 个交易日只能覆盖不到 1.5 年，未经历完整的牛熊周期。样本外需持续跟踪。

3. **幸存者偏差**：数据库只有 2024-12-18 之后的数据，之前退市的股票缺失。

### 6.2 建议的增强方向（后续迭代）

1. **市场状态开关**：判断当前是趋势市还是震荡市，切换动量/反转因子方向
2. **行业中性化**：在行业内选股而非全市场选，避免过度集中在某个行业
3. **市值分层**：大/中/小盘分开选股，避免选的全是小盘垃圾股
4. **流动性过滤**：剔除日均成交额 < 500 万的股票，避免流动性陷阱
5. **止损机制**：单只股票跌超 -15% 强制卖出

## 八、附录：因子经济学解读

### 为什么 A 股表现均值回归？

1. **散户主导的市场**：A 股散户占比高，追涨杀跌行为导致短期超买后必然回落
2. **机构波段操作**：公募基金考核周期短，频繁做波段，强化了反转效应
3. **缺乏做空机制**（对多数股票）：涨多了只能卖，形成自然天花板
4. **板块轮动快**：资金在不同板块间快速切换，单一板块动量难以持续
5. **监管因素**：涨停板制度和异常波动停牌打断了趋势的连续性

### 因子权重符号解读

- **负权重的动量** = "买最近涨得少的，卖最近涨得多的" = 反转策略
- **负权重的波动率** = "买波动小的" = 低波异象（A 股也存在）
- **正权重的 price_ma60** = "买在均线上方的" = 趋势过滤（基本面质量代理变量）
- **正权重的 close_low_20** = "买在区间低位的" = 经典反转信号
